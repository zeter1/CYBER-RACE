# Security Policy

CYBER RACE — browser-only WebGL game. Проект не требует аккаунта или серверной базы данных, но использует browser storage и внешние CDN для загрузки Three.js.

## Как сообщить об уязвимости

Не публикуйте потенциально опасные детали в публичном issue до первичной оценки.

Приватный контакт:

- Email: zeter11@gmail.com
- Telegram: https://t.me/zeter1

Укажите:

- версию браузера;
- затронутую ревизию;
- минимальные шаги воспроизведения;
- ожидаемый и фактический результат;
- влияние проблемы;
- безопасный proof-of-concept.

## Важные области

Особенно полезны сообщения о:

- XSS / script injection;
- небезопасной обработке данных из `localStorage`;
- подмене или неожиданном выполнении внешнего script/CDN content;
- проблемах, позволяющих выйти за ожидаемую browser sandbox-модель;
- утечке данных browser profile через приложение.

Не публикуйте cookies, токены, приватные данные профиля браузера или другие секреты.
