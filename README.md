# 🏎️ CYBER RACE: CAR WARS

[![Validate](https://github.com/zeter1/CYBER-RACE/actions/workflows/validate.yml/badge.svg)](https://github.com/zeter1/CYBER-RACE/actions/workflows/validate.yml)

**CYBER RACE: CAR WARS** — браузерная 3D-гонка на **Three.js/WebGL**, где обычная гонка объединена с автомобильным боем.

Игрок соревнуется с тремя AI-соперниками на трассе из 15 кругов, использует пулемёт, самонаводящиеся ракеты, нитро и защитный импульс, подбирает бонусы и старается одновременно выиграть гонку и пережить атаки соперников.

## Возможности

- 3D-графика на Three.js и WebGL.
- Гонка на 15 кругов.
- Игрок + 3 AI-соперника.
- Пулемёт.
- Самонаводящиеся ракеты с захватом цели.
- Нитро-ускорение.
- Защитный импульс, перехватывающий вражеские снаряды и замедляющий соперников.
- Дрифт и очки за занос.
- Боевые столкновения и система повреждений.
- Уничтожение и восстановление машин.
- Регенерация здоровья.
- Энергетический щит.
- ЭМИ-эффект.
- Бонусы на трассе:
  - ракеты;
  - патроны;
  - нитро;
  - ускорение;
  - ЭМИ;
  - здоровье;
  - щит.
- Мини-карта.
- Индикатор позиции в гонке.
- Предупреждение о ракете.
- Индикатор захвата цели.
- Определение неправильного направления движения.
- Комбо за уничтожение соперников.
- Рекорды лучшего круга, общего времени и очков.
- Три уровня сложности.
- Автоматический и ручной режим качества графики.
- Автоматическое снижение качества при низком FPS.
- Полноэкранный режим.
- Звук через Web Audio API.
- Пауза при потере фокуса или переключении вкладки.
- Восстановление после потери WebGL-контекста.

## Запуск

Проект состоит из одного основного файла:

```text
index.html
```

Можно открыть его напрямую в современном браузере, однако для наиболее предсказуемой работы рекомендуется запуск через локальный HTTP-сервер:

```bash
python -m http.server 8000
```

После этого откройте:

```text
http://localhost:8000
```

## Клонирование

```bash
git clone https://github.com/zeter1/CYBER-RACE.git
cd CYBER-RACE
python -m http.server 8000
```

## Требования

- современный настольный браузер;
- WebGL;
- JavaScript;
- клавиатура и мышь;
- интернет-соединение для загрузки Three.js с CDN.

Используется **Three.js 0.160.0**. Игра сначала пытается загрузить библиотеку с jsDelivr, а при ошибке — с unpkg.

## Настройки

В главном меню и меню паузы доступны:

- **Сложность**
  - Новичок
  - Обычная
  - Хардкор
- **Графика**
  - Автоматически
  - Высокая
  - Производительность
- **Звук**
- **Тряска камеры**

Настройки сохраняются в `localStorage`.

## Рекорды

В браузере сохраняются:

- лучший круг;
- максимальное количество очков;
- лучшее полное время гонки на 15 кругов.

Данные хранятся в `localStorage` и привязаны к браузеру / origin.

## AI соперников

Соперники:

- двигаются по трассе независимо;
- меняют полосу;
- избегают плотного сближения друг с другом;
- используют нитро;
- собирают бонусы;
- стреляют ракетами и пулемётом;
- получают щиты и другие эффекты;
- используют динамическое rubber-banding, чтобы гонка оставалась конкурентной;
- меняют точность, урон, скорость и частоту атак в зависимости от выбранной сложности.

## Производительность

Игра имеет два режима качества:

### Высокое качество

- повышенный pixel ratio;
- тени;
- больше частиц.

### Производительность

- уменьшенный pixel ratio;
- отключённые тени;
- уменьшенное количество частиц;
- отключённый `backdrop-filter` для части HUD.

В режиме **Автоматически** игра отслеживает FPS и переключает качество в зависимости от производительности.

## Диагностика

Если игра не запускается:

1. Откройте DevTools браузера через `F12`.
2. Проверьте вкладку **Console**.
3. Убедитесь, что браузер поддерживает WebGL.
4. Проверьте доступ к CDN Three.js.
5. Попробуйте запуск через локальный HTTP-сервер.
6. Если графика стала нестабильной, переключите качество в режим **Производительность**.

Если оба CDN Three.js недоступны, игра показывает сообщение об ошибке прямо в стартовом меню.

## Ограничения

- Текущая версия ориентирована прежде всего на ПК с клавиатурой и мышью.
- Three.js загружается через внешние CDN, поэтому полностью автономный офлайн-запуск требует локальной копии библиотеки.
- Весь код пока находится в одном HTML-файле.
- Полного browser end-to-end набора пока нет; интерактивный gameplay требует отдельной runtime-проверки.
- CI проверяет структуру HTML, синтаксис встроенного JavaScript и статическую раздачу проекта, но не заменяет реальную WebGL/gameplay-проверку.

## Проверка и CI

Workflow [`.github/workflows/validate.yml`](.github/workflows/validate.yml) запускается на изменениях `index.html` и самого workflow. Он проверяет:

- корректность HTML parsing;
- синтаксис каждого inline JavaScript-блока через `node --check`;
- отсутствие потерянных локальных ресурсов, если они появятся в разметке;
- отдачу `index.html` через локальный HTTP-сервер;
- diff hygiene через `git diff --check`.

Проверка **не заявляет**, что реальный WebGL/gameplay полностью протестирован: GPU, браузерный rendering loop, Web Audio и интерактивное управление остаются runtime-зависимыми.

### Рекомендуемый runtime smoke test

1. Открыть стартовое меню.
2. Проверить переключение сложности и графики.
3. Запустить гонку.
4. Проверить управление WASD / стрелками.
5. Проверить пулемёт и ракеты.
6. Проверить нитро и защитный импульс.
7. Проверить подбор бонусов.
8. Проверить паузу и возврат в игру.
9. Проверить полноэкранный режим.
10. Проверить завершение гонки и сохранение рекордов.
