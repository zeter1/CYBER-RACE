## Как читать runtime быстро

Нитро соперников: `planOpponentTactics` сначала оценивает пользу обгона (`tacticalPass`), затем проверяет `bend`, `chosen.risk` и готовность `nitroReady`. При допустимом манёвре `nitroCorridorClear` проверяет **весь поток машин**, включая объекты за прежними 200 единицами: за 2,5 секунды действия нитро рассчитывает продольное сближение и перестроение по 10 отрезкам, проверяя минимальное сближение внутри каждого отрезка (порог 11 единиц). Прогноз использует верхнюю оценку скорости `max(speed, baseSpeed * 1.2) * 1.7`; множитель 1.2 учитывает текущие пределы сложности (1.07) и rubber band (1.12) — при изменении этих пределов пересмотрите оценку и тесты. Следование за медленной машиной начинает снижать скорость уже при расстоянии менее 120 единиц. `stepOpponentFrame` расходует заряд только при `useNitro`. Сценарии безопасного обгона, стоящей машины, слияния полос, пересечения старта, далёких объектов и 30/60/144 FPS — в `tests/opponent-tactics.mjs`. Это приблизительный прогноз для планировщика, а не гарантия отсутствия столкновений при непредсказуемых манёврах.

Файл [src/game/runtime.js](../src/game/runtime.js) - одна асинхронная IIFE. Его локальные переменные не являются публичным API. Для точечного поиска из корня проекта, если установлен `rg`:

```powershell
rg -n 'function (updatePlayer|respawnPlayer|applyPlayerDamage)|canAcceptGameplayInput' src/game/runtime.js
rg -n 'stepOpponentFrame|planOpponentAttack' src/ai/opponent-brain.js src/game/runtime.js tests
rg -n 'stepHomingProjectile|segmentSphereHit3D' src/weapons src/game/runtime.js tests
```

Для задачи на другой участок подставьте имя из таблицы. В редакторе подходит обычный поиск символа. Читайте функцию-владельца, её входы и места вызова; расширяйте чтение только при реальной зависимости.

Логические участки runtime в порядке файла:

1. Проверка namespace, загрузка Three.js, DOM, settings и guards меню.
2. Классы эффектов, сцена, renderer, трасса, машины, бонусы, состояние игрока и рекорды.
3. Переходы меню/countdown/fullscreen и обработчики ввода.
4. Нитро, импульс, снаряды, смерть, respawn, restart, круги и финиш.
5. Обновление игрока, AI, бонусов, снарядов, камеры и HUD; FPS по реальному времени `requestAnimationFrame`, переключение качества только в `auto`.
6. Качество, главный цикл, resize/WebGL-события и boot marker.
